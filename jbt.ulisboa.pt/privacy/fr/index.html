Vie Privée

Les données personnelles vous appartiennent — Propriété.

La vie privée est respectée. Seuls l'utilisateur et l'agent connaissent les données personnelles — Confiance.

Les données personnelles ne sont jamais partagées avec des tiers — Confidentialité.

Les données personnelles sont collectées, stockées et utilisées de manière anonyme, c'est-à-dire distinctes de l'identité — Anonyme.

L'utilisateur est libre de désinstaller l'application et de supprimer toutes les données stockées localement — Liberté.

Les données de localisation seront collectées uniquement lors de l'utilisation de l'application — Emplacement.
