Privacidad

Los datos personales pertenecen al usuario — Titularidad.

Se respeta la privacidad. Solo el usuario y el agente conocen los datos personales — Confianza.

Los datos personales nunca se comparten con terceros — Confidencialidad.

Los datos personales se recopilan, almacenan y utilizan de forma anónima, es decir, la identidad separada de la información resultante — Anónimo.

El usuario es libre de desinstalar la aplicación y eliminar todos los datos almacenados localmente — Libertad.

Los datos de ubicación solo se recopilarán durante el uso de la aplicación — Localización.
